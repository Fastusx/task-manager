# Task Manager 

Um sistema de gerenciamento de tarefas (Task Management System) construído para facilitar a organização, criação e acompanhamento de atividades no dia a dia. O projeto foca em uma arquitetura backend robusta e de fácil execução.

## Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando as seguintes tecnologias:

*   **Java**
*   **Spring Boot**
*   **H2 Database** (Banco de dados em memória)
*   **Maven** (Gerenciamento de dependências)

## Funcionalidades

*   **Criar Tarefas:** Adicionar novas atividades ao sistema com título e descrição.
*   **Listar Tarefas:** Visualizar todas as tarefas cadastradas.
*   **Atualizar Tarefas:** Modificar o status ou detalhes de uma tarefa existente.
*   **Deletar Tarefas:** Remover tarefas que não são mais necessárias.
